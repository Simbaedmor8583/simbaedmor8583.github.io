🚀 What Is This?

This is a native PC port of the classic 1998 RPG-horror game PARASITE EVE, rebuilt specifically for modern Windows systems. Unlike emulators that simulate the original PlayStation hardware, this version uses static recompilation — the original game's code is translated and optimized to run natively on your PC. This means better performance, higher resolutions, and more stable gameplay.

❗ Please note: This project is a work-in-progress. Some features may be incomplete, but the core game is fully playable and optimized for 4K/60fps.

🎯 FAQ & Troubleshooting

❓ The game won't start. What should I do?

Make sure your graphics drivers are up to date. Also verify that your system meets the minimum requirements. If the problem persists, check the repository's Issues page for common solutions.

❓ Can I use a controller?

Yes! The game has full support for USB controllers. Simply plug in your controller before starting the game, and it will be recognized automatically.

❓ How do I save my progress?

The game supports manual saving at designated save points, just like the original PS1 version. You can also use the emulator-style quick save feature (F5 key) for saving anywhere.
